Fonts bundled so the PDF report renders the same on every server (no dependency on system fonts):
  DejaVuSans.ttf, DejaVuSans-Bold.ttf  - DejaVu fonts (free licence, see https://dejavu-fonts.github.io/License.html). Latin (incl. accents), Greek, Cyrillic, the rupee sign.
  FreeSans.ttf, FreeSansBold.ttf       - GNU FreeFont (GPLv3+ with the font-embedding exception, https://www.gnu.org/software/freefont/). Used only for names written in Devanagari.
The LearnIQ logo (learniq-logo.png) is the supplied file, unmodified.
